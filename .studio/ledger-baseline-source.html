Every application Ingenium Studio builds keeps a Build Ledger: time, scope, code, quality, and AI usage, from the first requirement to the latest release. This is Hoard's first: a local-first personal finance aggregator for Windows that keeps a household's bank, brokerage and property data in a private MySQL database. Releases 1.0 to 2.0.1 were built before Hoard joined the studio; this ledger measures the whole application as it stands, and in full the work since Oct 9 (Plaid as a second bank provider, account handover, budgets, interactive reports, an AI Advisor, three live-found defects fixed, and onboarding into Ingenium Studio), built by an AI engineering agent (Claude Opus 5.5).

Method

What these numbers cover

  • Token and time figures come from this project's three Claude Code sessions (Oct 9–18) only. Releases 1.0.0 to 2.0.1 (Sept 7–26) have no session record here, so none of their time or tokens is counted; their code is counted in the line totals.
  • Active time sums gaps of under ten minutes between logged events, so long waits for the user count as idle.
  • Model calls are counted once per API response; a response with several tool calls counts once. Prompts are the user's own messages, including the onboarding stage's request.
  • Work after the last commit (this ledger) is in the day totals but in no phase. Figures were collected while the ledger was being written, so its last few minutes are not included.
  • Tokens are not converted to cost.
  • Line counts are non-blank lines of tracked files at commit 3450f5b. "Lines of code, tests and tools" leaves Markdown out. Inserted and deleted lines are git's figures for the four non-merge commits since Oct 9; the Oct 2 import of 2.0.1 (17,678 lines) is not counted as churn.
  • Words are whitespace-separated tokens, table rules included.
  • Defects per 1,000 lines divide by lines inserted since Oct 9, because all four defects surfaced in or around that work.
  • The requirements and decision log were inferred from the code at onboarding, not written before the build.
