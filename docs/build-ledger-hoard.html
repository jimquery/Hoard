Hoard personal finance aggregator

Every application Ingenium Studio builds or manages keeps a Build Ledger: time, scope, code, quality, AI usage, and cost, from the first requirement to the latest release. This is Hoard personal finance aggregator's. It carries forward the app's own earlier ledger (docs/build-ledger-hoard.html) and adds everything since. Hoard is a local-first Windows app that syncs bank, brokerage (SimpleFIN, Plaid) and property (RentCast) data into a private MySQL database. It categorizes transactions with rules, tracks budgets and subscriptions, and produces interactive reports. An optional Claude-based advisor and a background Windows sync service are included. I wrote .studio/requirements.yaml, .studio/architecture.md, .studio/decisions.md and studio.yaml.
